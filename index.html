Serangan jaringan ↔ kontrol pertahanan

Merah menandai skenario ancaman, hijau menandai kontrol pertahanan; garis abu-abu menggambarkan hubungan konsep.

Generasi Teknologi Firewall

Firewall dapat memfilter ICMP Type 5 dan membatasi akses UDP pada layanan yang dilindungi, tetapi hanya mengendalikan trafik yang melewati titik inspeksinya. Firewall di sisi korban tidak dapat mengatasi saturasi link sebelum trafik tiba. Buka materi terkait

Alternatif diagram: hubungan dalam teks

  • ICMP Redirect → Firewall: aturan firewall dapat memfilter ICMP Type 5 sesuai desain jaringan [1][17]; baca materi ICMP Redirect.
  • NTP/Memcached UDP amplification → Firewall: firewall sisi layanan dapat membatasi eksposur reflector; firewall korban tidak menyelesaikan saturasi upstream [8][9]; baca materi Amplification.
  • Firewall: packet filtering hingga NGFW menawarkan jenis konteks inspeksi yang berbeda [13][14]; baca materi Generasi Teknologi Firewall.

Istilah kunci

Glosarium singkat

Buka istilah untuk definisi ringkas dan halaman tempat pembahasannya.

Reflection

Reflection adalah pola ketika request diarahkan ke server perantara dengan alamat sumber yang dipalsukan sehingga respons server dikirim ke pihak lain; dibahas di Amplification.

Amplification

Amplification terjadi ketika ukuran respons yang dipantulkan lebih besar daripada request, sehingga trafik ke tujuan dapat meningkat; dibahas di Amplification.

BAF · Bandwidth Amplification Factor

BAF adalah rasio ukuran byte respons terhadap ukuran byte request dalam konteks amplifikasi; dibahas di Amplification.

IP spoofing

IP spoofing adalah pemalsuan alamat IP sumber yang tampak pada paket; relevan untuk reflection dan dijelaskan di Amplification.

MITM · Man-in-the-Middle

Man-in-the-Middle adalah kondisi ketika pihak tak tepercaya berada di jalur komunikasi dan berpotensi mengamati atau mengubah trafik; peluang dan batasnya dibahas di ICMP Redirect.

ICMP Redirect

ICMP Redirect adalah pesan kontrol IPv4 yang memberi tahu host tentang gateway alternatif; pemalsuan atau penerimaan tanpa kehati-hatian dapat memengaruhi rute lokal, sebagaimana dibahas di materi ICMP Redirect.

Stateful inspection

Stateful inspection menilai paket dengan mempertimbangkan state koneksi/flow yang dicatat firewall; dibahas di Generasi Teknologi Firewall.

DPI · Deep Packet Inspection

DPI berarti pemeriksaan isi atau struktur paket lebih dalam daripada metadata header, sesuai kemampuan dan konfigurasi; dibahas di Generasi Teknologi Firewall.

NGFW · Next-Generation Firewall

NGFW adalah firewall yang menambahkan kemampuan di atas stateful firewall, seperti pengenalan aplikasi atau IPS, sesuai fitur dan implementasi; dibahas di Generasi Teknologi Firewall.

ICMP Redirect

Daftar lengkap ada di halaman topik masing-masing.

Daftar sumber pada halaman ICMP Redirect mencantumkan judul dan URL; penulis/tahun tidak ditampilkan di entri tersebut.

  1. [1] RFC 792
    Internet Control Message Protocol

    Format ICMP Redirect, Type 5, kode 0–3, Gateway Internet Address, header IP asli + 64 bit data, dan penjelasan fungsi sah Redirect.

  2. [2] RFC 1122
    Requirements for Internet Hosts — Communication Layers

    Persyaratan host untuk ICMP Redirect, termasuk pemeriksaan konteks dan perilaku host. Lihat bagian 3.2.2.2.

  3. [3] RFC 1812
    Requirements for IP Version 4 Routers

    Persyaratan router IPv4 terkait pembuatan dan pengiriman ICMP Redirect; berguna untuk konteks peran gateway.

  4. [4] Linux
    Dokumentasi kernel Linux: IP Sysctl

    Definisi accept_redirects, hubungan nilai global/interface dengan forwarding, serta default fungsional host/router.

  5. [5] Microsoft
    Microsoft Learn: netsh interface

    Referensi sintaks untuk netsh interface ipv4 set global, opsi icmpredirects, dan show global. Nilai default tidak ditetapkan di referensi tersebut, jadi periksa konfigurasi aktual.

  6. [6] Alamat demo
    RFC 5737: IPv4 Address Blocks Reserved for Documentation

    Alamat 192.0.2.0/24 dan 198.51.100.0/24 pada diagram adalah alamat dokumentasi.

NTP Monlist & Memcached Amplification

Daftar lengkap ada di halaman topik masing-masing.

  1. [7] NVD
    National Institute of Standards and Technology, “CVE-2013-5211 Detail”

    National Vulnerability Database, 2014. Rujukan CVE untuk kelemahan NTP mode-7 yang terkait dengan MON_GETLIST/monlist.

    Catatan verifikasi: halaman NVD memakai konten dinamis dan perlu diperiksa manual untuk detail deskripsi/versi terdampak.

  2. [8] Cloudflare
    Cloudflare, “Memcrashed - Major amplification attacks from UDP port 11211”

    2018. Menjelaskan reflection Memcached/UDP, contoh ukuran request/respons, dan rasio amplification yang diamati.

  3. [9] GitHub
    GitHub Engineering, “DDoS incident report”

    2018. Post-mortem insiden DDoS GitHub pada 28 Februari 2018, termasuk vektor Memcached dan respons mitigasi.

  4. [10] IETF
    Paul Ferguson & David Senie, “Network Ingress Filtering: Defeating Denial of Service Attacks which employ IP Source Address Spoofing”

    2000. RFC 2827 / Best Current Practice 38 (BCP 38), rekomendasi ingress filtering untuk membatasi pemalsuan alamat sumber.

  5. [11] NTP Project
    NTP Project, “ntpdc - special NTP query program”

    Dokumentasi seri NTP 4.2.8, diperbarui 2023. Menjelaskan ntpdc, mode-7, fungsi query, dan status antarmuka yang deprecated; sumber konteks untuk istilah monlist.

  6. [12] IETF
    David L. Mills et al., “Network Time Protocol Version 4: Protocol and Algorithms Specification”

    2010. RFC 5905, spesifikasi NTPv4; rujukan protokol untuk konteks port dan transport NTP.

  1. [13] NIST

  4. [16] IETF
    Jon Postel, “Internet Control Message Protocol”

    RFC 792, September 1981. Rujukan format dan jenis pesan ICMPv4; Type 5 adalah Redirect.

  5. [17] IETF
    Fred Baker, editor, “Requirements for IP Version 4 Routers”

    2014. Rujukan kelemahan NTP mode-7 yang berkaitan dengan potensi penyalahgunaan layanan NTP.

  7. [19] Cloudflare
    Cloudflare, “Memcrashed - Major amplification attacks from UDP port 11211”

    2018. Laporan teknis tentang penyalahgunaan instance Memcached/UDP yang terekspos dan mitigasi amplification.

  8. [20] IETF
    Paul Ferguson & David Senie, “Network Ingress Filtering: Defeating Denial of Service Attacks which employ IP Source Address Spoofing”

    RFC 2827 / BCP 38, Mei 2000. Best Current Practice tentang ingress filtering untuk membatasi pemalsuan alamat sumber IP.
